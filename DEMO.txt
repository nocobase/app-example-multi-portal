Multi-portal Example — ServiceHub

See README.MD (English) or README.zh-CN.md (Chinese) for installation,
accounts, the walkthrough, and screenshots.

English is the default interface language. Both languages share one fictional
English dataset spanning London, Amsterdam, and Singapore.
Enable app.sampleData before the first startup to create the demo accounts and records.
Restore demo data recreates the English business records without changing accounts.

Host maintenance:
  systemctl --user status servicehub-server servicehub-tunnel
  systemctl --user stop servicehub-server
  bash scripts/start-demo.sh

The host script requires the existing host configuration and compiled client.
New installations should follow pnpm dev in the README.
